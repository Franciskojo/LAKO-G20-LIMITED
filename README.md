# LAKO G20 LIMITED

> **Ghana's Premier Outdoor Advertising & Billboard Specialists**

LAKO G20 LIMITED is a modern, high-performance web platform showcasing premier out-of-home (OOH) media assets, prime arterial billboard locations across Accra, and turnkey fabrication & large-format printing services.

---

## 🚀 Key Features

- **Prime Hotspot Explorer**: Interactive discovery of high-impact billboard structures across Accra (Kwame Nkrumah Circle Interchange, Airport City, Spintex Road, Graphic Road, Motorway Entry, Osu Oxford Street).
- **Service Portfolio**: Unipoles, gantries, 3D illuminated channel letters, vehicle fleet wraps, retail mall activations, and point-of-sale branding.
- **Interactive ROI Calculator**: Real-time impressions, reach estimators, and quote simulations.
- **Live Billboard Simulator**: Interactive visual simulator for client campaigns.
- **Direct Quote & Inquiry System**: Instant booking workflows with WhatsApp integration.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite 6
- **Styling**: Tailwind CSS + Vanilla CSS Design System
- **Icons**: Lucide React
- **Animations**: Framer Motion & Canvas Confetti

---

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Franciskojo/LAKO-G20-LIMITED.git
cd LAKO-G20-LIMITED
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

---

## 🌐 Deployment

This application is ready for continuous deployment on **Netlify**, **Vercel**, or any static hosting platform.

- **Build Command**: `npm run build`
- **Publish Directory**: `dist`
